# 0026. Редизайн витрины: металлы отделки, плавная прокрутка, мобильные панели действия

Дата: 21.09.2026

## Контекст

Пользователь 21.09.2026 поставил задачу прямо: «вылизать дизайн сайта на всех страницах, сделать
максимально современным, обязательно проработать мобильную версию, оставить только гамму цветов и
логотип, добавить гладкое пролистывание, серебряные и золотые акценты — нужно дороже».

До этого `01_brand/DESIGN.md` §3 запрещал пятый цвет, §7 разрешал blur только на подложке
модальных окон, а `05_website-plan/21_interface-design.md` §1.5 закрывал список источников
постоянного движения четырьмя. Витрина Этапа 2 была собрана строго по этим правилам и читалась
пользователем как недостаточно дорогая.

## Решение

1. **Металлы — материал отделки, а не пятый цвет.** В тему добавлены шкалы `gold-300/500/700`
   и `silver-300/500/700` и два градиента (`--gradient-gold`, `--gradient-silver`). Правило
   размещения: золото — на кремовом и белом (тёплое к тёплому), серебро — на фиолетовых плитах и
   чернилах (холодное к холодному); крест-накрест не ставятся. Формы применения ограничены:
   надзаголовок с металлической чёрточкой (`.eyebrow`), волосяная линия (`.rule-gold` /
   `.rule-silver`), паспарту вокруг крупного кадра (`.frame-gold` / `.frame-silver`),
   металлический текст только дисплейного кегля (`.text-gold` / `.text-silver`: сумма, номер
   заказа, одно слово заголовка), знак ₽ рядом с суммой, бейджи товара, золотая волосяная линия
   внутри главной кнопки на наведении. Сплошных заливок металлом нет.
2. **Фиолетовая плита — с глубиной и зерном** (`.plate .grain`): градиент от `#a366c2` к
   `#5c3475` со средним тоном в фирменном `#9556b4`, поверх — шумовая текстура 9%.
3. **Стекло разрешено шапке и липким панелям** (`.glass`: полупрозрачный крем + blur) —
   исключение из правила §7 «blur только на модалках», принято пользователем в составе редизайна.
   Шапка липкая, после первого движения страницы сжимается (`html[data-scrolled]`).
4. **Плавная прокрутка — Lenis** (`components/site/site-motion.tsx`): колёсико с инерцией,
   касание на телефоне остаётся нативным, при `prefers-reduced-motion` библиотека не запускается.
   Появление блоков при прокрутке — чисто на CSS (`[data-reveal]`, `animation-timeline: view()`),
   без скрипта; браузер без поддержки показывает всё сразу.
5. **Два новых источника постоянного движения сверх четырёх из §1.5**, оба по прямому указанию
   пользователя «свежие современные идеи»: бегущая строка обещаний на главной (`Marquee`,
   пауза на наведении) и медленный блик по металлическому тексту (`.shimmer`). Оба гаснут при
   `prefers-reduced-motion`; на экранах оплаты их нет.
6. **Мобильная версия**: поле страницы `--gutter` 20px; ряды карточек на телефоне — ленты с
   прилипанием (`.scroller`), на широком — сетка; липкие нижние панели действия на карточке
   товара («В корзину» через `form=`) и в корзине («Оформить»); фильтры каталога — липкая
   стеклянная полоса под шапкой; меню — шторка во весь экран с дисплейной навигацией; цели
   касания ≥ 44px; отступ под системную панель (`.safe-bottom`, `viewport-fit: cover`).
7. **Формы и поверхности**: кнопки — пилюли (`xl` для первого экрана, `gold` — контур золотом);
   поля `.field`, карточки-выбор `.choice`; карточка `.card` с радиусом 22px и подъёмом на
   наведении, плиты 32px; общие заготовки экранов — `PageIntro` (крошки, надзаголовок, h1, лид)
   и `SectionHeading`. Компонентные классы живут в слое `components`, чтобы утилиты Tailwind
   могли их переопределять.
8. **Что не менялось**: палитра, логотип, шрифты Bergamasco / Manrope, бабочки (закрытая зона),
   композиционный язык §1 (каскад, плиты, фото за плиту, выносной заголовок, три насыщенные
   плиты на главной), поведение форм без JavaScript, маршруты, метаданные и микроразметка.

Код — репозиторий `visteria-website`, правки от 21.09.2026 (коммит с пометкой «редизайн» в `git log`).

## Последствия

- `01_brand/DESIGN.md` §3 дополнен разделом «Металлы отделки», §7 — стеклом шапки; копия в
  корне кода синхронизирована. `21_interface-design.md` §1.5 получил отметку о двух новых
  источниках движения.
- В `apps/web` появилась зависимость `lenis`. Второй библиотеки движения не заводить.
- Публичный каталог отдаёт бейджи товара подписями из справочника `badge`, а не UUID:
  до редизайна плитка рисовала первый бейдж как есть, и на живых данных это был бы
  идентификатор (обнаружено при просмотре, исправлено в SQL публичных полей `packages/db/src/catalog.ts`).
- Локальная проверка: перед просмотром витрины в локальной базе нужно применить миграции
  0008–0009 (`pnpm db:migrate`), иначе `GET /catalog/*` отвечает 500.

## Открытые вопросы

- Кадры товаров по-прежнему приходят из `MEDIA_BASE_URL`; зеркала фото МойСклад нет
  (`17_readiness-audit.md` §8.1), поэтому на живом каталоге плитки стоят с плитой-заглушкой.
- Иконка корзины в шапке без счётчика: число позиций потребовало бы чтения cookie на каждой
  странице и сделало бы статические страницы динамическими. Вернуться к этому вместе с
  дровером корзины (§3.6).
