# 05 — Публичный контракт API приведён в порядок

Требования: R01, R02, R03. Волна: 4. Blocked by: 03.
Зона: `apps/api`. Больше ничего.

Из брифа: «приступай к разработке таким образом чтобы соблюдать план который прописан там».

Почему таск есть. Разбор отложенных находок приёмки: семь пунктов по apps/api, каждый
ограниченный, и все они дешевле закрыть сейчас, чем оставить. Первые два нашли оба
независимых ревьюера, и оба касаются контракта, на который будет подключаться витрина.

Приёмка:
- [ ] Набор кодов ошибок в ответе совпадает с задокументированным. Сейчас `errors.ts`
      выдаёт `invalid_request`, `method_not_allowed` и запасной `error`, которых нет ни в
      `apps/api/README.md`, ни в контракте. Либо коды исчезают из ответа, либо появляются
      в документации — но расхождения не остаётся, витрина не должна ветвиться по
      незадокументированным значениям.
- [ ] CORS отвечает и на 429, и на preflight. Сейчас он зарегистрирован после лимита
      запросов, поэтому браузер видит ошибку CORS вместо тела с кодом лимита. Preflight
      публичный бюджет не расходует. Утверждено тестом, который краснеет, если порядок
      вернуть обратно.
- [ ] Белый список полей спускается внутрь `images`: сейчас элементы массива проходят
      целиком. Тест краснеет на лишнем поле внутри элемента изображения, а не только на
      лишнем ключе верхнего уровня.
- [ ] Тест «запрос не дойдёт до МойСклад» утверждает то, что названо в его имени —
      исходники, а не список зависимостей. Прямой вызов на api.moysklad.ru из `src`
      должен его красить.
- [ ] В журнале поле `code` несёт код ошибки, а не текст сообщения. Сообщение — отдельным
      полем. Сейчас `main.ts` кладёт туда текст `ConfigError`.
- [ ] Код `not_found` покрыт тестом: каждый код из таблицы контракта проверяется.
- [ ] `scripts` и `dependencies` в `apps/api/package.json` снова построчные. Свёрнутый в
      одну строку манифест даёт конфликт на всей строке при любой параллельной установке.

Существующие утверждения не ослаблять и не удалять. Новых зависимостей не ставить.
Не трогать: packages/**, apps/sync-worker, apps/web, apps/admin, корневые манифесты и
lockfile, .github, бренд и дизайн. Не коммитить.
