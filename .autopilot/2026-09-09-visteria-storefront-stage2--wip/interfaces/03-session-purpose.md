# Контракт назначения сессии

Читайте этот файл всем задачам, которые выдают или проверяют сессии.

`sessions.purpose` имеет значения `staff` и `client`, `NOT NULL DEFAULT 'client'`.
Служебный вход явно пишет `purpose='staff'`; управленка требует это назначение и на каждом
запросе перечитывает роль из `staff_allowlist`, проверяет `expires_at` и отзыв сессии.

Ссылка оптовика и будущий вход покупателя остаются клиентскими. `wholesale_request_id` не
является признаком назначения. `POST /admin/logout` гасит только служебную сессию.
