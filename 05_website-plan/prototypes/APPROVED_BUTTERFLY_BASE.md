# Согласованная основа анимации бабочки

Статус: **согласовано 3 сентября 2026 года**.

Основной файл: [`butterfly_codepen_reference_test.html`](./butterfly_codepen_reference_test.html)

Зафиксированные свойства:

- SVG-бабочка собирается из двух зеркальных половин;
- крылья вращаются в 3D вокруг шарнира `50px 50px`;
- диапазон взмаха: `60deg → -70deg → 60deg`;
- базовый спокойный цикл: `1s ease-in-out`;
- общий наклон: `rotate3d(1, .5, 0, 50deg)`;
- цвет адаптирован под фирменный фиолетовый «Вистерии».

Референс: https://codepen.io/JEFworks/pen/XzKJmv

Следующие эксперименты должны использовать этот файл как основу и не изменять его напрямую.

Согласованная механика полёта трёх бабочек и требования к переносу в боевую версию зафиксированы в [`APPROVED_BUTTERFLY_IMPLEMENTATION.md`](./APPROVED_BUTTERFLY_IMPLEMENTATION.md).
