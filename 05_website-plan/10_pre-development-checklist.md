## 2. Юридическое/бизнес — нужно для запуска реальных продаж, не только для кода

- **Реквизиты компании** (ИП/ООО, ИНН) — требуются для договора с платёжным провайдером и для чеков.
- **Онлайн-касса (54-ФЗ)** — при приёме онлайн-оплаты физлицам обязательна пробивка чека; уточнить, встроена ли она в выбранный платёжный провайдер (у большинства решений РФ — да, но это нужно подтвердить, а не предполагать).
- **Политика обработки персональных данных** (152-ФЗ) — юридический текст для формы регистрации/заказа, уже упомянуто в `08_nonfunctional-security-ops.md` §1, но сам текст политики должен подготовить заказчик/юрист.
- **Публичная оферта** — условия продажи, доставки, возврата (актуально: цветы — скоропортящийся товар, нужна чёткая политика по браку/некондиции при получении).
