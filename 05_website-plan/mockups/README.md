## Измеренные признаки приёмки

Замерено в браузере на 1440×900 по `../21_interface-design.md` §1.7:

| Признак | Норматив | Факт |
|---|---|---|
| 1. Цвет заливкой | ≥ 25% площади первого экрана | **29%** |
| 2. Один крупный элемент | главный ≥ 2× следующего | **2,71×** (фотография против заголовка) |
| 3. Постоянное движение | назван источник кроме отклика | **три бабочки + дыхание фотографии** |
| 4. Фото больше текста | площадь фото > площади текста | **1,52×** |
| Мобильность | нет горизонтальной прокрутки | **scrollWidth = clientWidth** на 390px |

Полёт проверен: через 5 секунд все три бабочки в воздухе, к 19-й секунде садятся ровно в свои точки — заголовок, кнопка «Смотреть каталог», бейдж на фотографии.

## Как смотреть

Открыть `hero-home.html` двойным щелчком. Кнопка «Повторить полёт» в правом нижнем углу запускает сценарий бабочек заново. При системной настройке «уменьшить движение» бабочки остаются сидеть, а фотография перестаёт дышать — это требование, а не сбой.
