# Вистерия — сайт цветочного магазина (Челябинск)

Проектная база знаний и техническое задание на разработку продающего сайта
с интеграцией МойСклад, личным кабинетом (розница + опт) и управленческой
админкой. Кода в репозитории пока нет — это этап подготовки к разработке.

## Где что лежит

| Папка | Что внутри |
|---|---|
| `01_brand/` | фирменный стиль, дизайн-токены, шрифты (`DESIGN.md` — то, что читает impeccable) |
| `02_company/` | профиль компании, контакты, адреса |
| `03_social-media/` | выгрузки VK и Instagram |
| `04_research/` | заметки, конкуренты, референсы |
| `05_website-plan/` | техническое задание на сайт, файлы `00`–`16` |
| `.autopilot/` | ход сборки: требования, спецификация, таски, дашборд |

## Как здесь работает Autopilot

Сборка ведётся навыком `/autopilot`. Требования, спецификация и таски — в `.autopilot/`.
Прогресс — `.autopilot/dashboard.html`. Правило: требование из `manifest.md`
может снять только пользователь.

Если работа продолжается — скажи «продолжи автопилот»: состояние поднимется
из `.autopilot/state.js`, переспрашивать ничего не нужно.
